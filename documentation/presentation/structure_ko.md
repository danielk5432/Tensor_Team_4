# 저차원 텐서 분해와 이미지 인페인팅 응용

## 1. 서론 (Introduction)

### 연구 배경
행렬 분해(Matrix Decomposition)는 데이터 압축, 노이즈 제거, 특징 추출 등 다양한 분야에서 활용되고 있다.

그러나 이미지, 비디오, 다중 채널 센서 데이터와 같은 실제 데이터는 행렬보다 고차원 구조를 가지므로 텐서(Tensor) 형태로 표현하는 것이 자연스럽다.

저차원 텐서 분해(Low-Rank Tensor Decomposition)는 이러한 고차원 데이터를 효율적으로 표현하고 복원하기 위한 핵심 기법이다.

### 연구 목표

본 연구에서는 주어진 텐서를 저차원 텐서로 근사하는 문제를 다룬다.

특히 CP 분해와 Tucker 분해를 구현하고 성능을 분석한 뒤, 이를 이미지 인페인팅(Image Inpainting) 문제에 적용하여 저차원 텐서 모델의 복원 성능을 평가한다.

### 연구 내용

* CP-ALS 알고리즘 구현
* Tucker 분해 구현
* 저차원 근사 성능 분석
* 수렴성 및 강건성 평가
* 이미지 인페인팅 응용

---

## 2. 저차원 텐서 분해 (Low-Rank Tensor Decomposition)

### CP 분해

CP(Canonical Polyadic) 분해는 텐서를 여러 개의 Rank-1 텐서 합으로 표현하는 방법이다.

특징

* 가장 직관적인 텐서 랭크 표현
* 파라미터 수가 적음
* ALS 알고리즘을 통해 최적화 가능

장점

* 압축 효율이 높음
* 구조가 단순함

단점

* 초기값에 민감
* 지역 최적해(Local Minimum)에 수렴 가능

### Tucker 분해

Tucker 분해는 코어 텐서(Core Tensor)와 여러 개의 인자 행렬(Factor Matrix)로 텐서를 표현한다.

특징

* 다중 랭크(Multi-linear Rank) 사용
* 높은 표현력 제공
* HOSVD 및 HOOI 기반 최적화 가능

장점

* 복원 성능 우수
* 표현 유연성 높음

단점

* 파라미터 수 증가
* 계산량 증가

### 성능 평가 지표

본 연구에서는 다음 지표를 사용하였다.

#### 상대 오차 (Relative Error)

원본 텐서와 복원 텐서 간의 차이를 측정

#### Frobenius Norm

텐서 전체 재구성 오차 측정

#### PSNR

복원 이미지 품질 평가

#### SSIM

구조적 유사도 평가

#### Runtime

알고리즘 수행 시간

## 3. 수학적 분석 (Mathematical Analysis)

### CP-ALS 최적화 문제

주어진 텐서를 Rank-R 텐서로 근사하도록 최적화 문제를 구성한다.

ALS 알고리즘은 하나의 인자 행렬을 갱신하는 동안 나머지 행렬은 고정하는 방식으로 반복 수행된다.

업데이트 과정

1. A 업데이트
2. B 업데이트
3. C 업데이트
4. 수렴할 때까지 반복

### 수학적 검증

구현의 정확성을 확인하기 위해 다음 실험을 수행하였다.

#### Exact Rank-2 Tensor

정확히 Rank-2인 텐서를 생성하여 복원

목표:
복원 오차가 0에 가까운지 검증

#### Noisy Rank-2 Tensor

노이즈가 포함된 Rank-2 텐서 복원

목표:
노이즈에 대한 강건성 확인

#### Random Tensor

일반적인 랜덤 텐서 근사

목표:
실제 상황에서의 근사 성능 평가

### 성능 분석

다음 요소를 중심으로 분석하였다.

#### 수렴 특성 (Convergence)

반복 횟수에 따른 오차 변화 분석

#### 초기값 민감도 (Initialization Sensitivity)

초기화 방식에 따른 결과 비교

#### 노이즈 강건성 (Noise Robustness)

노이즈 수준 변화에 따른 성능 분석

## 4. 응용: 이미지 인페인팅 (Applications: Image Inpainting)

### 실험 환경

사용 데이터셋

* Lena
* Baboon
* Peppers
* House
* Boats
* Airplane

RGB 이미지를

Height × Width × Channel

형태의 3차 텐서로 표현하였다.

또한 임의의 마스크를 생성하여 손실 영역을 구성하였다.

### Ground Truth 및 구현 방법

#### CP 기반 인페인팅

과정

원본 이미지
→ 손실 이미지
→ CP 분해
→ 복원 이미지

CP-ALS를 이용하여 저차원 표현을 학습하고 결측 영역을 복원하였다.

#### Tucker 기반 인페인팅

과정

원본 이미지
→ 손실 이미지
→ Tucker 분해
→ 복원 이미지

HOSVD/HOOI를 이용하여 복원을 수행하였다.

### 성능 분석

다음 항목을 비교하였다.

#### Rank Sweep

랭크 변화에 따른 성능 변화 분석

#### 노이즈 강건성

노이즈 환경에서의 복원 성능 비교

#### 시각적 복원 결과

* Ground Truth
* Masked Image
* CP Reconstruction
* Tucker Reconstruction

을 비교하여 복원 품질을 평가하였다.

## 5. 결론 (Conclusion)

### 연구 요약

본 연구에서는 CP 분해와 Tucker 분해를 직접 구현하고 저차원 텐서 근사 문제를 분석하였다.

또한 수렴성, 초기값 민감도, 노이즈 강건성 등을 평가하고 이를 이미지 인페인팅 문제에 적용하였다.

### 주요 결과

* CP 분해는 효율적인 저차원 표현 제공
* Tucker 분해는 우수한 복원 성능 제공
* 저차원 텐서 모델이 결측 데이터 복원에 효과적임을 확인
* 이미지 인페인팅 문제에서 텐서 분해 기법의 활용 가능성 확인
